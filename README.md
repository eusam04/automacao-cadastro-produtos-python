## ✨ Sobre o Projeto

Esta automação foi criada para realizar o cadastro automático de produtos em um sistema, simulando ações do usuário como:

- abrir o navegador
- acessar o sistema
- realizar login
- ler os dados de uma planilha CSV
- preencher e cadastrar os produtos automaticamente

O objetivo do projeto é otimizar tarefas repetitivas, economizando tempo e reduzindo erros manuais.
